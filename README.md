Vídeo de uso 2 prints da tela do Teachable Machine (uma do painel de treino e outra do modelo acertando/errando um teste).
Pequena Reflexão (3 a 5 linhas): O modelo cometeu algum erro durante os testes? Por que você acha que isso aconteceu (iluminação, poucos dados, fundo poluído)?

Usamos o modelo de treinamento de imagens. Para a coleta de dados das fotos nas classes, acessamos o WhatsApp Web onde se encontravam as selfies. São duas classes: "Sem óculos" e "Com óculos". Cada classe contém 30 fotos ou mais. A IA conseguiu reconhecer o Vitor quando ele tirou o óculos. Todavia não conseguiu reconhecer o Samyr quando o mesmo colocou o óculos. Creio que foi devido a uma quantidade baixa de fotos. Imaginamos que se fosse uma quantidade de 100-150 fotos haveria uma precisão melhor. A iluminação também não estava das melhores. Ademais, devido as classes terem uma pessoa apenas para representá-las(Classe "sem óculos" só tinha o Samyr e a Classe "Com óculos" só tinha o Vitor) e, por causa disso, provavelmente o modelo teve dificuldade de reconhecer. Possivelmente, de acordo com os testes realizados nesse projeto, a máquina deve ter uma precisão de 75% de acerto.

Alunos: Samyr e Vitor.
